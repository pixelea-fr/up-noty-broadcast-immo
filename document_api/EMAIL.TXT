
 
Comme convenu, voici les informations techniques à connaitre pour la récupération de biens immobiliers depuis Noty.
 
Noty Broadcast est la plateforme développée par Noteo pour simplifier les échanges entre les outils de négociation et les partenaires (sites internet, carrousel de biens, etc).
Il s'agit d'une API HTTP REST entièrement évolutive qui suit les standards d'OpenAPI v3 afin de garantir la meilleure interopérabilité possible.
Elle retourne un flux JSON global ou incrémental. Elle gère le multi-étude (récupération de plusieurs offices notariales en même temps si nécessaire).
Une documentation privée, en ligne et à jour est accessible pour tous les partenaires : https://broadcast.noty.fr/doc/destination
